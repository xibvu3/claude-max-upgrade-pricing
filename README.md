## 升级 5x 到 20x，当下只需要补差价

官方 Max 只有两档，价格是没有讨价空间的那种清晰：

- Max 5x：**100 美元/月**
- Max 20x：**200 美元/月**

两个数字都是网页订阅价，不含税，而且 Max 目前只有月付，没有年付折扣。官方帮助中心也写得很直白：包括 Max 5x 和 20x 在内，付费计划不提供常规折扣价。所以指望等一波促销再升，基本不用等。

从低档升到高档时，账号会按剩余账单周期**按比例补差价**，不会重复收你一整月的钱。这一点和很多人的直觉不一样，值得记住：升级动作本身不是再买一份订阅，而是把当前周期的差额补齐。

有两个入口需要单独注意：

1. **Google Play 订阅**：升级时按新套餐全价扣费，旧套餐未使用的价值会折算成额外天数，所以你的续费日期会比整月晚几天。
2. **年付 Pro 转 Max**：如果年付 Pro 的剩余余额高于 Max 的价格，官方会给账户一个余额抵扣（credit），用于之后的订阅费用。前提是账单地址和之前一致——地址变了的话，得先取消 Pro、等到订阅结束日，再用新地址买 Max。

## 「20 倍」算在哪一层，决定了你升完之后会不会继续撞墙

这是整个话题里最容易被误解的地方。

5x 和 20x 描述的是**每 5 小时会话窗口相对 Pro 的用量倍率**。会话窗口每 5 小时滚动重置一次，这一点两档一样。Max 额外还有一条**跨所有模型的周上限**，周上限在分配给账号的固定时间点重置，不管你什么时候开始使用、什么时候开始订阅，都不会挪动，每个周期给满额。

问题就出在这两层是独立运作的。谁先到，谁先卡你。如果你的用法是短时间高强度跑 Claude Code，天天卡在周上限上，那么把会话窗口从 5 倍拉到 20 倍，对你的帮助远小于价格标签暗示的程度。官方从来不公布各档对应的 token 绝对数量，只给相对倍率，用户端看到的是一根百分比进度条，没有办法自己验算倍率是否兑现——围绕这一点已经有订阅者提起诉讼，称实际到手大约只有 6 到 8 倍，案件目前没有实质裁决。这是争议，不是结论，但它至少说明一件事：**别把 20 倍当成一个可以换算成小时数的承诺。**

功能层面的差异反而很小，两档 Max 拿到的是一套东西：

- 所有任务更高的输出上限
- 新模型和新功能的早期访问
- 高峰期优先访问

而 Claude Code、Cowork、Design 这些能力 Pro 就有。升到 20x 不会让模型变快，也不会让回答变准。多出来的只有「能用的量」。如果你的痛点是等待时间或者回答质量，升档解决不了。

## 具体怎么升：路径不长，坑在细节

升级本身在网页端设置里的计划页面完成，点几下就好。真正需要提前确认的是这几件事：

2. **确认账单地址。**如果你是从年付 Pro 过来，地址不一致会拿不到余额抵扣。
3. **走应用商店订阅的，先接受全价扣费。**余额会变成额外天数，续费日会往后挪，别以为扣错了。

## 几个被问得最多的问题

**升到 20x 之后，周额度会重置吗？**
不会额外重置。每周的完整额度每个周期照常发放，但重置时间点是账号固定值，不随订阅时间或升级动作变化。

**5x 和 20x 的功能一样吗？**
功能基本一致，差别在用量上限层级和价格。早期功能访问、高峰期优先权这类权益，两档 Max 都有，Pro 没有。

**Max 能年付吗？**
目前不行，官方明确只提供月付。想降低单次操作频率的，只能接受按月扣。

**升档会让回答变快、变聪明吗？**
不会。同一个模型，同样的响应质量。你要是因为等太久想升级，先确认瓶颈是排队还是额度，两者不是一回事。

**如果升完发现还是不够？**
额度耗尽后可以开按量付费继续跑，按 API 标准价计费，记得把月度上限设窄一点，不然月底账单会给你上一课。
